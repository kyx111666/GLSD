# G/L 条件区分与逐尺度机制诊断 v1

本轮明确检查灰区阈值以外的因素：参考尺度a0的候选覆盖、局部半径rho、跨尺度峰对齐容差gamma、median聚合和缺失支持记零。它是下一轮选择调参对象的实验，不搜索新的灰区low/high/eta组合，也不重启S_beta/max。

## 会做哪些计算

沿用用户实际Drive封存runner/core和官方评价器，不替换为本地近似实现。每个被试：

- 用原来的L和Gray配置各回放一次full路径，逐项核对事件、GT、计数和候选分数与这轮旧结果一致。
- 对a0={1,1.5,2}各导出一次全部原候选的官方区间，仅走raw spotting用于取得几何，不重跑backbone、不做新识别训练。
- 在相同候选池上记录rho={.5,1,2,3}的证据，前三点与原结构重合，rho3是一个有限的局部窗口探针。
- 记录每个物理尺度的对齐局部分数、是否有匹配峰、所选峰距离、最近峰距离以及实际窗口/容差。
- 同一结构分别计算gamma={.25,.5,.75,1}的median；.5必须逐候选精确重建封存L（仅容许浮点容差）。gamma改变时遵守原距离优先、局部分数次优的匹配规则；固定候选和rho时，扩大gamma只会补入原先缺失的尺度匹配，已有最近匹配不变，默认median不会下降；因此更要检查它是否同时抬高背景分数。
- 在默认gamma=.5下比较median、算术mean、仅对成功匹配尺度取median；不改支持尺度集合、不改变峰间距或事件宽度。后两者是机制探针，不作为新完整方法或新的F1结果。

最多新增615次被试级解码调用：123被试×（2次旧选中配置full回放+3次全部候选raw导出）。证据特征计算和条件模型另计。与前轮5460配置搜索不同，本轮没有逐阈值、逐融合配置运行完整解码。

只允许读取已完成grayzone输入，输出在新的诊断目录。逐项复核旧manifest记录的dump、源码和证据哈希、dump清单与继承代码。相同源码的旧封存core副本只用于本地测试（SHA256与两套旧manifest匹配），实际运行不会导入测试副本作为core。

## 条件区分能力怎么验证

所有结构分别报告，**不会看外层结果选最好的a0/rho再拼出一行成绩**。

1. 用原官方IoU函数计算候选区间与GT的重合。`geometry_eligible=1`表示该候选至少能与一个GT达到IoU>=.5。它是“具备几何匹配条件”，不是最终TP；多个候选可能覆盖同一GT，尚未包含识别过滤。
2. 在每个固定a0/rho下，按被试LOSO比较两个固定诊断模型：仅L与L+G。特征先做固定截断logit变换；每折标准化、拟合只用训练被试，各训练被试总权重相同。使用固定ridge=1e-3，不调正则系数、不搜模型；比较留出被试的log loss。
3. `delta_LG_minus_L<0`表示加入G后对几何可匹配性的概率判断更好。报告各被试变化与条件于已拟合预测的10000次被试配对bootstrap。没有重拟合bootstrap，也没有多结构/反复开发校正，区间不能直接作论文独立显著性结论。
4. 同时给出更直观的训练侧L分位数分组；在每个L组内，用训练侧G中位数切分留出候选，报告高/低G组的几何可匹配比例。分组边界不看留出标签，重复分位数自动合并。
5. 对rho/gamma/聚合探针，分别统计几何可匹配与不可匹配候选的L变化、缺失支持比例、分数增加/降低至少.05的比例。该.05仅为预先固定的效果描述阈值，不用于筛选候选、不重算F1。观察是否只是把两类候选一起抬高。

这一步首先验证证据的几何区分能力。即使结果正向，仍需在训练侧选参、重新完整匹配和识别后才能证明最终full F1受益；如果仅几何探针好看而full路径失败，也不能声称模块成功。

## 如何据结果决定下一轮调什么

- gamma变化主要修复可匹配候选缺失支持，且背景候选增分较少：优先做**对齐容差的单因素完整评价**。
- rho2→3主要增强可匹配候选而不过度抬高背景：优先做**局部窗口的有限范围调参**。
- median相对mean/匹配尺度median对真实候选有系统性压低，且替代聚合有条件区分增量：优先做**聚合或缺失支持机制对照**。
- G在控制L后仍有稳定条件信息，但以上证据问题不突出：优先改**融合决策/校准**，减少自由度。
- a0候选覆盖差异明显：检查**参考尺度选择**，不要只归咎阈值；覆盖是上限诊断，不以GT挑a0作正式结果。
- 如果正负候选同步增分、G条件增量不稳定：不立即扩网格，先报告没有定位到可利用的机制证据。

不会以这轮诊断自动选择“最好看”的探针并更新论文。真正下一轮完整方法与G/L对照要共享证据变体和公平的调参机会。

## 返回结果内容

每数据集目录：

- `run_manifest.json`、`matching_protocol.json`、`completion.json`。
- `subjects/*.json.gz`：逐视频全部候选、官方区间和GT、几何可匹配ID、默认G/L与每物理尺度证据/距离、各单因素探针。
- `conditional_summary.csv`、`conditional_folds.csv`：固定结构下L/L+G留出比较，负delta表示G有额外信息。
- `heldout_L_bins_G_groups.csv`：训练定义L分组内的G条件差异。
- `scale_effects.csv`：对齐/聚合探针的两类候选响应。
- `radius_effects.csv`：固定a0与候选时，相邻rho变化的两类响应。
- `candidate_GT_coverage.csv`：每被试、每a0的候选GT几何覆盖；不等于一对一召回或full召回。
- `analysis_notes.json`：标签、训练隔离和解释范围。

本地测试与ZIP/cell对应检查见`VALIDATION.json`。本轮真实官方导出尚待Colab执行；本地已完成的只有旧结果归因和程序验证。

# ME-TST+ 训练自由推理解码审计（2026-09-01）

## 研究约束

- 冻结 ME-TST+ backbone，不更新任何模型参数。
- 方法只能使用推理输出的逐帧 spotting score、emotion logits，以及确定性的测试时变换。
- 主评测沿用论文的 subject-independent 协议、IoU=0.5、Spotting F1、三情绪 Recognition F1 与 STRS。
- ICASSP 2027 完整论文截止为 2026-09-16；技术内容限 4 页，因此只保留一个核心机制。

## 基线代码审计

原始解码器对 spotting score 做宽度 `2*k_p` 的移动平均，使用 Moilanen 阈值

`T = mean(s) + 0.55 * (max(s) - mean(s))`

寻找间距至少为 `k_p` 的峰，并输出固定对称区间 `[peak-k_p, peak+k_p]`。情绪通过区间内逐帧硬标签多数投票得到。

由此得到四个限制：

1. `k_p` 同时控制平滑、峰间距和边界，三个不同作用被绑定。
2. 单次平滑下出现的偶然峰与跨尺度稳定峰没有区别。
3. onset/offset 必须关于 peak 对称，不能表达非对称响应。
4. 单次原图推理无法利用水平镜像下应保持不变的事件时间和情绪语义。

这些计数用于定位失败机制，不替代官方最终指标。结论是：只改边界无法解决大多数 FN；候选稳定性与误峰抑制必须同时处理。

缓存中另有少量 GT 顺序异常或越界记录。正式主结果必须原样沿用官方评测口径，异常只作为数据限制披露，不能为了提高结果私自删除。

## 当前候选：EquiScale Inference Decoder

给定原视频和水平镜像的冻结输出，先在相同时间轴平均 score 与 logits：

`s_bar(t) = (s(t) + s_mirror(t))/2`

然后围绕基线尺度 `k` 构造五个无量纲尺度：

`K = {2k/3, 4k/5, k, 5k/4, 3k/2}`。

每个尺度独立平滑、阈值化和找峰；将邻近峰聚为同一事件。只有获得至少三个尺度支持的峰簇才保留，这个阈值来自五尺度多数原则，不按数据集调节。最终 onset、peak、offset 由支持成员按照视频内分位校准置信度加权得到。

核心主张应限定为：

> 冻结时序预测中的真实事件应同时满足输入变换等变性和时间尺度稳定性；利用两种一致性可以在不拟合任何参数的情况下完成候选筛选与边界聚合。

## 新颖性风险

- DMA-ME-Spotting（2024）已经使用多尺度/多模式窗口和多数投票；论文不能把“多尺度投票”本身写成创新。
- 学长交付源码中已有朴素 mirror-output averaging（B3/TTA）实验代码；不能把镜像平均单独据为新贡献。
- 可以检验的新部分只能是“变换等变证据与尺度持久性联合定义事件可靠度，并直接替换固定峰解码器”。是否足够新颖，必须由老师在看到 DMA、RethinkFuse 和 B3 的关系后确认。
- 当前 PoC 在完整数据上形成，存在研究者选择偏差。正式结果必须冻结规则后重跑，并报告全部尝试和参数敏感性。

## 下一道验收门槛

只有同时满足以下条件才进入论文写作：

1. 固定算法后，两个数据集均超过原始 ME-TST+；
2. subject-level paired bootstrap 至少在一个数据集给出稳定增益，另一个不显著退化；
3. 完成 `original only`、`mirror only`、`average only`、`scale only`、`full` 消融；
4. 与 RethinkFuse/AGF 公平比较，并明确本方法完全 training-free；
5. 老师确认可使用学长包中的 mirror cache，且作者贡献与知识来源清楚。
